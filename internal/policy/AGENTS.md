# Rules for `internal/policy`

Before changing a rule here, read its history with `git log -S '<words from the line>'`.

- Opening a FIFO for reading: first ask a private level-triggered epoll (Linux) or kqueue (darwin, BSD) whether data or a hang-up is present, and only when there is no data do a 1-byte non-blocking read, where `EAGAIN` means a writer is present. Reading first loses a byte for other readers. Do not use `ioctl(FIONREAD)`, which needs `unsafe`, and never open the other end yourself to end a wait. A blocking `syscall.Open` in tests needs an `EINTR` retry loop.
- Cancelling a blocked read of a FIFO or device: read in place and end it through the file itself, as `special_unix.go` does (a past deadline where the file is pollable, otherwise non-blocking reads that watch the context). Closing the file does not end a FIFO read on darwin, and a background reader goroutine keeps OS threads and takes the next reader's bytes.
- Resolving a path across mounts: keep the raw components and the symlink-origin boundary of each one (`filePart{name, boundary}`) through Root and FS redirects. Do not `path.Clean` or `path.Join` early; that misresolves `link/../file`. A parent step that comes from a link target may not leave its origin root, while a caller-supplied parent keeps virtual mount semantics. A backend without `ReadLinkFS` rejects listed symlinks throughout the source.
- An FS source overlaps a shadowed mount: enforce the disk-directory Root contract on the opened file (Open, then Stat, close and deny when `os.SameFile` recognises the OS file; also close on a Stat error). Names and `ReadLinkFS` cannot see OS hard links. Do not classify a backend by `Sys() != nil`, and do not copy inode scans into arbitrary FS code; opaque adapters remain trusted host code.
- Validating a network grant: normalise the host first, then validate, and reject a wildcard whose domain is only dots. Validating before removing the trailing dot accepted `*.`, which became `*` and allowed every destination.
- Deciding whether one physical Root contains another: walk host-controlled ancestor paths and compare directory identities with `os.SameFile`. Do not use string prefixes, `EvalSymlinks` plus `filepath.Rel`, or `EqualFold`; they miss a writable mount inside a read-only tree and case aliases on a case-insensitive volume.
- Handling Windows junctions: `os.Root.Lstat` reports a junction as `ModeIrregular`, not `ModeSymlink`, and `Root.Readlink` returns the absolute target as it was created. Resolve it as an absolute link into a granted mount or outside-root, because PHP follows junctions like directories. `filepath.EvalSymlinks` does not follow junctions, mount path matching folds case on Windows only, and a link-derived `..` that leaves a mount root continues through `linkParentMount`, never by looking up names in ungranted directories.
