"PHP memory-limit" programs recurse without bound; PHP ends them with
"Allowed memory size of 134217728 bytes exhausted" and Phego, which does not
meter memory, ends them at its frame or step limit. In every such program
Phego's output is a prefix of PHP's (checked with head -c | cmp).

The generator's parameter defaults never warn, so the RECV_INIT cache is
covered by the s2_def_cached_* and s2_def_uncached_kinds probes instead.
