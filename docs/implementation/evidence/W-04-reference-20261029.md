## 重跑固定主機名稱的參考執行

先取得固定映像與來源封存檔，將 `SOURCE` 設為封存檔絕對路徑，從此分支根目錄執行。下列重跑命令額外在建置失敗時印出診斷；當次成功執行使用相同建置條件，沒有這個失敗輸出處理：

```sh
docker run --rm --pull never --hostname phego-reference --platform linux/arm64 \
  --network none --read-only --user 65534:65534 --cpus 2 --memory 2g --pids-limit 256 \
  --cap-drop ALL --security-opt no-new-privileges --tmpfs /tmp:rw,nosuid,nodev,exec,size=2g \
  --mount "type=bind,src=$SOURCE,dst=/input/php.tar.xz,readonly" \
  --mount "type=bind,src=$PWD/tests/runner/phpt-fixtures,dst=/input/fixtures,readonly" \
  buildpack-deps@sha256:2d7fd9aab90c5444e6c4f5c59fce9ab6ba6bce7b8709ef74fcd1f618cd2e867b \
  timeout --kill-after=5s 1800s sh -c 'set -eu
export SOURCE_DATE_EPOCH=1792540800 TZ=UTC LC_ALL=C NO_INTERACTION=1 REPORT_EXIT_STATUS=1
cp /input/php.tar.xz /tmp/php.tar.xz
printf "08bc2eba2a588654ade1357174aa646b761556c862dda0678345ee29ed481209  /tmp/php.tar.xz\n" | sha256sum -c -
mkdir /tmp/build /tmp/fixtures
cp /input/fixtures/*.phpt /tmp/fixtures/
tar -xf /tmp/php.tar.xz -C /tmp/build
cd /tmp/build/php-8.5.12
./configure --disable-all --enable-cli --without-pear >/tmp/configure.log 2>&1 || { result=$?; cat /tmp/configure.log; exit "$result"; }
make -j2 >/tmp/make.log 2>&1 || { result=$?; cat /tmp/make.log; exit "$result"; }
./sapi/cli/php -n -v
sha256sum ./sapi/cli/php
set +e
TEST_PHP_EXECUTABLE=/tmp/build/php-8.5.12/sapi/cli/php ./sapi/cli/php -n run-tests.php -P /tmp/fixtures/*.phpt
result=$?
set -e
printf "REFERENCE_RUNNER_EXIT=%s\n" "$result"
'
```

此命令的外層成功只表示建置及執行流程到達結尾。必須另核對 `REFERENCE_RUNNER_EXIT` 與逐案例結果；不要把刻意的失敗改成跳過。兩次僅涵蓋同一 Linux arm64 核心、單一版本與 CLI 設定，沒有驗證 Phego、完整官方測試、其他平台或跨主機重現。
