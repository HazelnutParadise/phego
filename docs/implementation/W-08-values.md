# W-08 Go 值的局部實作

此部分對應 REQ-007、T-013 與 T-014 的資料表示及複製要求。完整情境仍是 `not_run`，因為 Go 執行入口、PHP 執行及請求結束後的結果快照尚未整合。

`phego.Value` 支援 null、布林、64 位元整數、浮點數、位元組字串及有序陣列輸入。`Bytes` 和 `Array` 複製輸入，讀取位元組或陣列時也回傳副本。巢狀值可共用，因其內容只能透過回傳副本讀取。

陣列輸入保留呼叫者給定的鍵與順序。PHP 8.5.12 的請求記憶體已具備數值字串鍵、重複鍵與 32／64 位元整數範圍轉換，但尚未與 Go 執行入口連接。其他版本仍未實作。物件、resource、callback 與輸出快照也尚未接入。

局部驗證入口：`CGO_ENABLED=0 go test ./...`、`go test -race ./...`、`CGO_ENABLED=0 go vet ./...`。這些檢查不代表 PHP 相容性或完整工作包驗收通過。
