## 實作與測試位置

`internal/ir/ssa/ssa.go` 定義不可變 Program、值、型別與來源契約，`build.go` 建立密集值表並限制編譯資源，`analyze.go` 實作兩個可個別關閉的 pass。`internal/ir/effects.go` 修正未知操作及診斷的效果低估。設計選項、實測及限制見 [W-15 SSA 決策](../decisions/W-15-ssa.md)。

`internal/ir/ssa/*_test.go` 驗證別名位置、未知效果、來源單調聯集、profile、容器額度、取消、不可變快照與並行讀取。`internal/runtime/optimization_w15*_test.go` 用既有 runtime 核心比較 off、各 pass 與全開，包含 PHP 警告、例外、動態變數、參照及解構。`tests/optimization/w15/reference.php` 與兩份參考固定每 profile 285 案，`.github/workflows/semantics-optimization.yml` 在原生 runner 重建固定映像參考。

基準入口在 `internal/ir/ssa/bench_test.go`。實際命令、原始記錄及輸入識別放在 [W-15 SSA 證據](evidence/W-15-ssa.json)。公開 Go 嵌入 API 沒有修改，核心不需 cgo 或 LLVM。

## 局部結果與剩餘整合

- 64／32 位元 PHP 8.5.12 各 285 案與四種 pass 組合一致，包含每 profile 256 組固定種子隨機算式。fuzz 另外比較 runtime 開關差異。
- 安全／能力／配額／取消操作都保持 ordered，不做移動或刪除。這是正式編譯契約的模型測試，真實 VM 與政策整合須由 W-17／W-21／W-39 重跑。
- 來源類別 metadata 有界且單調，摺疊不刪 origin 或 operand edges。W-21 的實際字串區段追蹤尚未完成。
- 本輪只建立不提升位置的值 SSA。完整 CFG、phi 與跨區塊傳播未實作，也沒有靠它們取得任何效能主張。
- W-11 登錄的編譯期常數診斷缺口仍在 `internal/ir/corpus_gaps_test.go`。局部運算 pass 不代表 `(1+1)::class`、常數陣列串接或完整 PHP 編譯相容已通過。

T-031／T-032 的完整驗收由 W-17 負責，其餘六項由 W-39 負責，均維持 `not_run`。下一個前置依賴已滿足的整合工作為 W-16，其 W-11／W-14 已在 main，PR #76 尚未合併。

## 輸入、狀態與失敗處理

SSA 入口接收 context、不可變 `ir.Unit` 與編譯選項，驗證精確 release、guest 整數寬度、short_open_tag 及資源上限。build profile 與能力授權由後續執行入口負責，SSA 只保留對應操作。可共用的 Program 不含請求內可變狀態。

| 情境 | 處理與可觀察結果 | 驗證責任 |
|---|---|---|
| 正常輸入 | 產生保留來源與效果的值 SSA，runtime adapter 比對 PHP 參考 | 本票局部回歸 |
| nil／缺少必要欄位 | nil context、Unit、Main、參數或 capture 回錯誤，不回傳部分 Program。錯誤目前是編譯 API 錯誤，沒有虛構來源位置 | 本票輸入邊界測試 |
| 空字串／空集合／零 | 空函式與空字串合法，Passes=0 關閉最佳化。節點／深度必須為正，新增常數字串額度可為零 | 本票輸入邊界測試 |
| 外部服務／活 handle | SSA 不存取外部服務，也不接收 runtime handle，故不適用。執行時的錯誤與權限由 W-17／W-20 整合 | 本票確認操作仍保留 |
| 重複／並行 | 同一不可變 HIR 可重複建圖，Program 可並行讀取。回傳的 roots 與常數快照不能修改內部值 | 本票 race 與快照測試 |
| 取消／超額 | context 取消、節點／容器／深度超限回錯誤與 nil Program。新增常數字串額度不足只放棄該次摺疊 | 本票失敗與額度回歸 |
| 已提交副作用／清理失敗 | Build 不執行 PHP，故沒有副作用提交或 Execution 清理。runtime adapter 驗證既有 W-14 清理，完整執行仍由 W-17 驗收 | 本票局部 adapter 與下游整合 |

下列情境的最終驗收負責票負責完整整合，局部編譯與 adapter 證據不構成完整情境通過。

## 相容、安全與範圍

維持 Go 單函式嵌入、預設不依賴 cgo／LLVM、第一版 PHP 起的全部歷史範圍、有界 goroutine、請求隔離與 Apache／Nginx FastCGI。任何後端都保留能力檢查及取消語意，正式執行不回退 Zend。

本票不發布軟體、不部署正式環境、不使用真實付款或郵件、不改第三方 PHP 程式來規避相容問題。付費、金鑰、正式權限、破壞性資料處理及產品方向變更需另外取得明確授權。
