# W-01 契約局部驗收紀錄

檢查對象為提交 `fd411b6104c2b58d702a82167c7d936e7fc1c76e` 的[契約與威脅檢查](../../decisions/W-01-contract.md)、[決策登錄](../../decisions/README.md)及[工作包計畫](../W-01.md)。規格版本為 1.1.2。此紀錄只涵蓋文件契約，不是引擎、相容性或安全功能的驗收。

## 局部檢查

| 工作包交付條件 | 審查結果與依據 |
|---|---|
| 已確認方向與本版基準分開 | 決策登錄的 28 筆狀態與規格第 28 章對照；已取代與實驗項目均保留其狀態。 |
| 入口、信任、資料流、能力與不變條件 | 契約涵蓋五種入口、三種信任情境及共用能力路徑。I-01 至 I-12 的清單與規格第 3 章對照；測試另檢查編號集合與重複項。 |
| 威脅與後續責任 | 契約列出請求隔離、資源存取、後端旁路、無效輸入、清理、程序隔離、來源追蹤、稽核及跨版本風險。所列工作包與原始工作包紀錄核對。 |
| 授權分類 | 契約記錄本次實作、推送與合併授權，並保留正式 release、正式環境、付費、資料破壞及產品承諾改變需另行授權的條件。 |

獨立審查先檢查提交 `49a2e681ea3fdf204b041deedc06b0420a23cf77`，指出契約票與引擎測試責任衝突，以及來源追蹤、稽核與跨版本威脅缺漏。提交 `fd411b6104c2b58d702a82167c7d936e7fc1c76e` 修正這些項目，並由整合者對照規格第 3、5、10、11、28、36 章及相關工作包。未新增改變架構方向的決策。

## 可重跑檢查與限制

於 macOS arm64、Python 3.9.6 執行：

- `python3 tools/validate_docs.py`：33 項文件檢查通過。
- `python3 -m unittest discover -s tools -p 'test_*.py'`：12 項測試通過。
- `tools/test_contract_document.py` 比較規格與契約的不變條件編號，不能驗證文字語意或引擎行為；文字對照由上述審查處理。

REQ-001、REQ-077、REQ-078 的完整完成條件及 T-001、T-002、T-153 至 T-156 尚未通過。本票的 null、並行、取消及清理等引擎行為留給相關實作票與各情境負責票。PHP 原始來源、歷史參考環境、引擎、真實網站與競品測量均未在此執行。此文件不宣稱效能改善或已部署任何安全措施。
